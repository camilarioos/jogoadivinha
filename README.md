# 🎮 Jogo de Adivinhação em Python

Um jogo de terminal clássico e divertido onde o jogador tem **7 tentativas** para adivinhar um número secreto gerado aleatoriamente entre **1 e 100**.

---

## 🚀 Como Funciona

1. O computador escolhe um número aleatório de 1 a 100.
2. O jogador insere um palpite.
3. O jogo dá dicas informando se o número secreto é **maior** ou **menor** que o palpite.
4. O jogador vence se acertar dentro das **7 oportunidades**. Caso contrário, o jogo revela a resposta.

---
